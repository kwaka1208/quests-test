# FAQ (phonebook 1.4)

> **Note:** This is the documentation for phonebook **1.4**.
> For the latest version, see [the 2.x documentation](../v2/faq.md).

## `search()` returns `None`. Why?

The person is not in the book. Check the spelling. Upper and lower case matter.

## Can I edit a book file by hand?

Please don't. The notes are encoded.
