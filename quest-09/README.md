# Quest 9: The Help Forum

> **このクエストのねらい**
>
> Q&A サイトの回答を、そのまま信じずに読み比べます。採用された回答が古いこと、得点の高い回答が間違っていてコメントで訂正されていることを経験します。エラーメッセージで検索し、duplicate で閉じられた質問から元の質問をたどります。

カスタマーサポートの Yui の画面には、いつも同じサイトが開いている。

「これ？ **Northwind Answers**。チームの Q&A フォーラム。行き詰まったら、まずここを検索する」

Stack Overflow と同じしくみだという。質問があって、回答がついて、みんなが点をつける。

「めちゃくちゃ助かるよ。でも、うのみは危険。古い回答もあるし、堂々とまちがってる回答もあるから。最初の1件で止まらないこと」

このクエストで読むのは、Q&A サイトの **質問と回答**（英語）です。

## 進め方

フォーラムを参考に3つのスクリプトを直し、実行します。

    python mapping.py
    python export.py
    python tickets.py

うまく動くと、スクリプトが単語を表示します。その単語でステージに答えます。

    python quest.py --stage 1
    python quest.py --stage 2
    python quest.py --stage 3

## ファイル

| ファイル | 中身 |
| --- | --- |
| `forum/` | Q&A フォーラム。`forum/index.md` から読み始める。Web サイトでも読める（下の「フォーラムの開き方」） |

## フォーラムの開き方

Northwind Answers は、Web サイトとして公開されています。ブラウザで開きましょう。

https://kwaka1208.github.io/northwind-developers/answers/

同じ質問と回答が、このクエストの `forum/` フォルダにも入っています。中身は同じなので、どちらを読んでもかまいません。

## Q&A のページの読み方

1つのページには、**質問**が1つと、**回答**がいくつかあります。次のところを見ましょう。

| 部分 | わかること |
| --- | --- |
| Score | 役に立ったと思った人の数。高いのはよい印だが、正しいという約束ではない |
| ✔ Accepted | 質問した人が選んだ回答。**その人の、その時点では**うまくいった |
| answered 2016 | 書かれた時期。古い回答は、新しいバージョンでは動かないことがある |
| Comments | ほかの人のメモ。訂正や注意は、ここに書かれていることが多い |
| Edit: | 回答者があとで書き直した部分。新しい情報が入っていることが多いので読む |
| Closed as a duplicate | 同じ質問が前にもあった。リンクをたどって元の質問を見る |

よく見る言葉です。

| 言葉 | 意味 |
| --- | --- |
| as of Python 3.9 | Python 3.9 から |
| does not work anymore | 前は動いたが、今は動かない |
| removed in 3.10 | 3.10 以降にはない |

回答を写す前に、次のことをしましょう。

1. 最初の回答だけでなく、回答を**全部**読む
2. **コメント**を読む
3. **日付**と **Python のバージョン**を確かめる

自分の Python のバージョンは、`python --version` で確かめられます。

## エラーメッセージで検索するには

エラーが出たら、`TypeError:` のような**エラーの種類で始まる行**で検索します。ふつうは最後の行ですが、Python のバージョンによっては、その下に補足の行が続きます。ファイル名や行番号のように、自分のコードだけに関係する部分は外します。

Web サイトでは、上の検索窓に言葉を入れます。入れた言葉がすべて含まれる質問だけが残ります（質問・回答・コメントが検索の対象です）。

`forum/` フォルダで探すときは、ファイルの中を検索します。

VS Code（Codespaces の画面）では、`Ctrl+Shift+F`（Mac は `Cmd+Shift+F`）を押して、言葉を入力します。

ターミナルでは、次のようにします。

    grep -rn "words from the error" forum/

## 困ったとき

**`NotImplementedError: Write this function` と出る**

まだ関数を書いていません。`raise NotImplementedError(...)` の行を、あなたのコードに置き換えてください。

**`IndentationError` と出る**

関数の中の行は、先頭に空白が4つ必要です。ほかの関数の書き方を見てみましょう。
