# How do I check if a value works like a dictionary?

**Asked by** @kaito-m · **Tags:** `python` `dictionary` · **Score:** 52

I have a function that takes a value. If the value is a dictionary (or something that works like one,
such as `OrderedDict`), I want to do one thing. If not, I want to do another thing.

How can I check this?

---

## Answer · Score: 45 · ✔ Accepted · answered 2016

Use `Mapping` from the `collections` module:

```python
from collections import Mapping

def is_mapping(value):
    return isinstance(value, Mapping)
```

**Comments**

- **@daiki-ops** (2022): This gives `ImportError` on Python 3.10 and later.
  `Mapping` was moved to `collections.abc` a long time ago, and the old name was removed in 3.10.
- **@yui-dev** (2023): Same here. It does not work anymore. See the answer with the highest score.

## Answer · Score: 120 · answered 2019

On Python 3, import it from `collections.abc`:

```python
from collections.abc import Mapping

def is_mapping(value):
    return isinstance(value, Mapping)
```

This works for `dict`, `OrderedDict`, `UserDict`, and your own classes that are registered as a `Mapping`.

## Answer · Score: 12 · answered 2017

Just compare the type:

```python
def is_mapping(value):
    return type(value) == dict
```

**Comments**

- **@misaki-w** (2020): This returns `False` for `OrderedDict` and `UserDict`. It only works for plain `dict`.

## Answer · Score: -3 · answered 2021

Check if it has `keys()`:

```python
def is_mapping(value):
    return hasattr(value, "keys")
```

**Comments**

- **@haruka-m** (2021): Any object can have a method called `keys`. That does not make it a dictionary.
