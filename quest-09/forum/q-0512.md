# How do I read a CSV file?

**Asked by** @yui-dev · **Tags:** `python` `csv` · **Score:** 40

I have a file `orders.csv`. How do I read it line by line?

---

## Answer · Score: 60 · ✔ Accepted · answered 2017

Use the `csv` module:

```python
import csv

with open("orders.csv", newline="", encoding="utf-8") as f:
    for row in csv.reader(f):
        print(row)
```
