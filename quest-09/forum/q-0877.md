# How do I save a date with json.dumps?

**Asked by** @haruka-m · **Tags:** `python` `json` `datetime` · **Score:** 88

My data has a `datetime.date` in it. When I call `json.dumps(data)`, I get:

    TypeError: Object of type date is not JSON serializable

How can I save the date?

---

## Answer · Score: 140 · ✔ Accepted · answered 2018

JSON has no type for dates, so `json` does not know how to write one.
Give `json.dumps()` a function with the `default` parameter.
`json` calls it for every value that it cannot write by itself.
The simplest function is `str`:

```python
text = json.dumps(data, default=str)
```

A date becomes a string like `"2026-11-11"`.

See the documentation of `json.dumps`: https://docs.python.org/3/library/json.html#json.dumps

## Answer · Score: 30 · answered 2020

You can also change the date to a string yourself before you save:

```python
data["date"] = data["date"].isoformat()
text = json.dumps(data)
```

This is fine when you have only one date.
