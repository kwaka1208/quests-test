# TypeError when I save my order to JSON

**Asked by** @tomoki-s · **Tags:** `python` `json` · **Score:** 1

> **Closed.** This question is a duplicate.
> This question already has an answer here:
> [How do I save a date with json.dumps?](q-0877.md)

I save an order with `json.dumps()`, and I get this error:

    TypeError: Object of type date is not JSON serializable

What is wrong?

---

## Answer · Score: 2 · answered 2025

Just delete the date before you save:

```python
del order["date"]
text = json.dumps(order)
```
