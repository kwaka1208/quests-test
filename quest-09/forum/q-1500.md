# How do I remove a prefix from a string?

**Asked by** @daiki-ops · **Tags:** `python` `string` · **Score:** 75

I have IDs like `ticket-42` and `ticket-kettle`. I want to remove `ticket-` from the start,
and get `42` and `kettle`. How can I do this?

---

## Answer · Score: 310 · answered 2015

Use `lstrip()`:

```python
def clean(ticket_id):
    return ticket_id.lstrip("ticket-")
```

**Comments**

- **@kaito-m** (2019): This is wrong! `lstrip()` does not remove a prefix.
  It removes every character in the string you give it (`t`, `i`, `c`, `k`, `e`, `-`), from the left.
  Try it with `ticket-kettle`: you get `le`. (Score: 205)
- **@yui-dev** (2020): Wow, I used this for years. Thank you for the warning.

## Answer · Score: 95 · ✔ Accepted · answered 2016

Check the start, and cut it off:

```python
def clean(ticket_id):
    if ticket_id.startswith("ticket-"):
        return ticket_id[len("ticket-"):]
    return ticket_id
```

**Edit (2021):** As of Python 3.9, strings have a method for this: `removeprefix()`.

```python
def clean(ticket_id):
    return ticket_id.removeprefix("ticket-")
```

Both versions work on Python 3.9 and later. On older versions, use the first one.
