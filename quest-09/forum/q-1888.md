# json.loads says "Expecting value"

**Asked by** @kaito-m · **Tags:** `python` `json` · **Score:** 22

When I read my JSON file, I get:

    json.decoder.JSONDecodeError: Expecting value: line 1 column 1 (char 0)

---

## Answer · Score: 41 · ✔ Accepted · answered 2021

The text is empty, or it is not JSON at all. Print the text before you call `json.loads()`,
and check that the file is not empty.
