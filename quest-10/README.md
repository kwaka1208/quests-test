# Quest 10: The Good Question

> **このクエストのねらい**
>
> Q&A サイトに出す質問を英語で書きます。具体的な疑問文のタイトル、それだけで問題が再現できる短いコード、実際の出力、試したことをそろえます。

テスト担当の Kaito が、ランチアプリの画面を指さした。

「3ドルのランチで2ポイント。5ドルのランチ**でも**2ポイント。……なんで？」

Haruto も Daiki も首をひねる。誰も理由がわからない。

すると Yui がにっこりした。

「じゃあ、フォーラムで聞いてみようよ。ただし、雑な質問はスルーされる。いい質問なら、10分で答えが来る」

前のクエストでは、質問と回答を**読み**ました。このクエストでは、質問を英語で**書き**ます。

## 進め方

まず、おかしな結果を見てみます。

    python points.py

`question.md` に質問を書いたら、チェックします。

    python check.py --stage 1

ステージの課題に合格すると、チェッカーが単語を1つ表示します。その単語で、同じステージに答えます。

    python quest.py --stage 1

ステージは2つあります。順番に進めてください。

## ファイル

| ファイル | 中身 |
| --- | --- |
| `points.py` | ランチのポイント。どこかおかしい |
| `question.md` | あなたの質問。**このファイルを編集します** |
| `check.py` | 質問をチェックし、単語を表示する |

`points.py`・`check.py` は編集しないでください。

## よい質問とは

答える人は忙しく、あなたのコンピューターを見ることもできません。
必要なものを全部、次の順で渡しましょう（見出しと中身は英語で書きます）。

| 見出し | 書くこと |
| --- | --- |
| Title | 質問を1行で。`?` で終わる、本当の質問の文 |
| What I want to do | やりたいこと（目的）を1〜2文で |
| Code | 問題が見える、**いちばん短い**コード。**それだけで**動くこと |
| What happened | 本当の出力や、本当のエラー。写して貼る。何を期待していたかも書く |
| What I tried | もう試したことをリストで。同じことを何度も勧められずにすむ |

タイトルを比べてみましょう。

| よくない | よい |
| --- | --- |
| `Help!!!` | `Why does int("3.5") give a ValueError?` |
| `URGENT: Python problem` | `How do I sort a list of dictionaries by a key?` |
| `My code does not work` | `Why does my loop stop after the first item?` |

### それだけで動く、短いコード

これを **minimal reproducible example**（最小の再現例）と呼びます。読む人があなたのコードを写して実行すると、同じ問題が見える、というものです。そのために、

- 問題を見せるのに要らない行は、すべて消す
- 自分のファイルを `import` しない。読む人はそのファイルを持っていません。必要な行をコードブロックに写す
- コードはコードブロックに入れる

  ````markdown
  ```python
  print(int("3.5"))
  ```
  ````

コードを短くしているうちに、自分で答えが見つかることもよくあります。それでもかまいません！

コードを短くするには、次の順で進めます。

1. おかしな結果を出しているコードを写す（たとえば `points.py` の関数）
2. 関数の呼び出しを、その中身の計算に置き換える。引数には実際の値を入れる（`price` → `5`）
3. 1行消すたびに実行し、**まだおかしいか**を確かめる。おかしくなくなったら、その行は必要だったので戻す
4. 最後に残った1〜3行が、質問に貼るコード

## ステージ1：質問を埋める

`question.md` を開きます。タイトルを書き、`TODO` をすべて置き換えてください。

    python check.py --stage 1

## ステージ2：答えやすくする

質問をもっとよくします。チェッカーは、空のフォルダで、あなたのコード**だけ**を実行します。

- タイトルは `?` で終わる質問の文（5〜20語）。"help" や "urgent" は書かない
- **What I want to do** は、ちゃんとした文で書く
- **Code** は、10行以内の `python` のコードブロック。それだけで動き、おかしな結果を表示する
- **What happened** には、本当の出力を1行そのまま入れる。コードブロックがおすすめ
- **What I tried** はリストで書く

      python check.py --stage 2

## 困ったとき

**「コードだけを実行したら、エラーで止まりました」と出る**

コードが、コードブロックの外にあるもの（`points.py` など）を必要としています。
`import` する代わりに、必要な行をコードブロックに写してください。
