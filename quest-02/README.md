# Quest 2: The Kind Error

> **このクエストのねらい**
>
> 相手を責めずに「何が起きたか」と「次に何をすればよいか」を伝える、短い英語のエラーメッセージを書きます。乱暴な文を落ち着いた文にし、次に役に立つ2文に直します。

昼休み。社内のランチ端末（キオスク）の前に、行列ができていた。なぜか、みんな微妙な顔をしている。

「ランチアプリ自体は人気なんだよ。でも、メッセージがね……」

カスタマーサポートの Yui が、端末をにらみながら言う。

「昨日なんて、新しく来た人が1文字打ちまちがえただけで、画面に怒鳴られてた。あれは泣く」

試しに、でたらめな単語を打ってみる。`ERROR!!!` ——たしかに、これは感じが悪い。

「というわけで、メッセージを書き直してほしい。お願い！」

前のクエストでは、エラーメッセージを**読み**ました。

このクエストでは、エラーメッセージを英語で**書き**ます。

## 進め方

まず端末を動かして、どんなメッセージが出るか見てみましょう。

    python kiosk.py

`messages.json` のメッセージを書き直したら、チェックします。

    python check.py --stage 1

ステージの課題に合格すると、チェッカーが単語を1つ表示します。その単語で、同じステージに答えます。

    python quest.py --stage 1

ステージは2つあります。順番に進めてください。

## ファイル

| ファイル | 中身 |
| --- | --- |
| `kiosk.py` | ランチ端末。小さなアプリ |
| `messages.json` | 端末が表示するメッセージ。**このファイルを編集します** |
| `check.py` | メッセージをチェックし、単語を表示する |

`kiosk.py`・`check.py` は編集しないでください。

## 優しいエラーメッセージとは

優しいエラーメッセージは、

1. **落ち着いている**：怒鳴らない（`ERROR!!!`）。相手を責めない
2. **何が起きたかを言う**："There is no item called 'pizza'."
3. **次に何をすればよいかを言う**："Type 'menu' to see what we sell."
4. **短い**：相手はランチを食べたいのであって、文章を読みたいわけではない

比べてみましょう。

| 優しくない | 優しい |
| --- | --- |
| `INVALID INPUT!!!` | `I don't know the word 'jmup'. Try 'jump'.` |
| `Error: no key.` | `The door is locked. Find a key first.` |

## プレースホルダー

メッセージの中に、相手が入力したものを表示できます。名前を `{ }` で囲んで書きます。

    "I don't know the command '{command}'. Type 'menu' to see what you can do."

相手が `dance` と入力すると、端末はこう表示します。

    I don't know the command 'dance'. Type 'menu' to see what you can do.

この `{command}` のような部分を、**プレースホルダー**（差し込み文字）と呼びます。プログラムが、ここに本当の値を差し込みます。

`messages.json` で使えるプレースホルダーは次のとおりです。

| プレースホルダー | 表示されるもの |
| --- | --- |
| `{command}` | 相手が入力したもの |
| `{item}` | 相手が注文しようとした品物 |
| `{price}` | 品物の値段 |
| `{money}` | 相手の所持金（ドル） |
| `{limit}` | トレイに載せられる品物の数 |

## ステージ1：怒鳴るのをやめる

`messages.json` の3つのメッセージは乱暴です。
落ち着いた、丁寧な文に書き直してください。

    python check.py --stage 1

## ステージ2：相手を助ける

次に、同じ3つのメッセージを役に立つ文にします。
どのメッセージも、**短い文を2つ**にしてください。「何が起きたか」と「次に何をすればよいか」です。
チェッカーは、プレースホルダーを使って相手に情報を見せることも求めます。

    python check.py --stage 2

## 困ったとき

**`messages.json が壊れています` と出る**

JSON を壊してしまっています。メッセージにある行（line）と列（column）を読みましょう。`,` や `"` が抜けていないか確かめます。

**端末を動かすと `KeyError` が出る**

プレースホルダーの名前がまちがっています。チェッカーを実行すると、使える名前を教えてくれます。
