# Quest 17: The Review Room

> **このクエストのねらい**
>
> 自分の PR に付いたコードレビューを読みます。Approve・Comment・Request changes の違いと、`nit`・`optional`・`question`・`blocking` の重さの違いを読み分け、マージ前に必ず直すものだけを直します。

ついに出した。**Pull Request #58**。「ポイントの謎」の修正だ。

通知を開くと、レビューが3件。コメントがずらりと並んでいる。

……こんなに直すの？

「落ち着いて」Misaki が笑った。「レビューは成績じゃない。助けだよ。それに、コメントが全部『直して』って意味とは限らない。思いつきもあれば、ただの質問もある。マージの前に必ず直すものは、ほんの少し。それを見分けよう」

このクエストで読むのは **コードレビューのコメント**（英語）です。

## 進め方

`review.md` と `points.py` を読みます。それから3つのステージに取り組みます。

1. レビューとコメントを仕分けます。`triage.txt` に答えを書いて、実行します。

       python triage.py

2. `points.py` で、直さなければならないところだけを直し、テストを実行します。

       python test_review.py

3. Kaito の小さなコメントにも対応して、実行します。

       python test_review.py --nit

どの手順も、合言葉（code word）を表示します。その単語でステージに答えます。

    python quest.py --stage 1
    python quest.py --stage 2
    python quest.py --stage 3

## ファイル

| ファイル | 中身 |
| --- | --- |
| `review.md` | あなたのプルリクエストへのレビュー |
| `triage.txt` | **ここでコメントを仕分けます（ステージ1）** |
| `triage.py` | `triage.txt` をチェックする。編集しない |
| `points.py` | プルリクエストのコード。**ステージ2・3で直します** |
| `test_review.py` | テスト。編集しない |

"Triage"（トリアージ）は、たくさんのものを見て、どれから手をつけるかを決めることです。

## レビューの3つの種類

GitHub では、レビューする人は次のどれかでレビューを終えます。

| レビュー | 意味 |
| --- | --- |
| ✅ **Approve** | 「マージしてよい」 |
| 💬 **Comment** | 「私の考えを書いておくね」。承認でもないし、止めるものでもない |
| ❌ **Request changes** | 「マージの前に、何かを変えてほしい」 |

大事なのは、言葉だけでなく、レビューの種類です。

## コメントの重さ

多くのチームでは、コメントの最初にラベルをつけます。

| ラベル | 意味 | 変える必要は？ |
| --- | --- | --- |
| `blocking:` | 本当の問題 | **ある。マージの前に** |
| `nit:` | 名前や言葉のような、とても小さなこと（"nitpick"：あら探し） | ない。やりたければやる |
| `optional:` | 思いつき。決めるのはあなた | ない |
| `question:` | レビューする人が理解したいだけ | 変えない。返事で答える |

よく見る言葉です。

| 言葉 | 意味 |
| --- | --- |
| LGTM | Looks good to me.（いいと思う） |
| Feel free to ... | よければ…してもいいよ |
| Not a big deal. | 大したことじゃない |
| must / should be | 必要だ |
| Just curious. | 知りたいだけ |

## 困ったとき

**`triage.py` が「少なくとも1行がまちがっています」と言う**

どの行かは教えてくれません。それぞれのレビュー（Approve？ Comment？ Request changes？）と、
それぞれのコメントの最初のラベルを確かめましょう。

**「points() が変わっています」や「describe() が変わっています」と出る**

blocking ではないところを変えて、テストが壊れました。変えるのは blocking のものだけです。

**`points.py` を壊してしまい、最初からやり直したい**

このフォルダで `git restore points.py` を実行します。
